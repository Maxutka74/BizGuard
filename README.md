# BizGuard

BizGuard допомагає захищати Gmail від фішингу, підозрілих посилань, небезпечних вкладень і спроб викрадення облікових даних.

Сервіс аналізує листи за допомогою AI, перевіряє домени та URL через VirusTotal, оцінює технічні ознаки повідомлення й показує зрозумілий рівень ризику.

## Можливості

- вхід через Google;
- аналіз листів із Gmail;
- AI-оцінка змісту повідомлення;
- перевірка домену відправника;
- перевірка URL і вкладень;
- оцінка ризику від 0 до 100;
- рівні `Safe`, `Medium`, `High` і `Critical`;
- пояснення причин небезпеки;
- рекомендації щодо подальших дій;
- фоновий моніторинг відповідно до тарифу;
- список довірених відправників на річному тарифі;
- автоматичне переміщення критичних листів у spam, якщо це дозволено тарифом.

BizGuard працює тільки з електронними листами Gmail. Це не антивірус для всього комп’ютера.

## Як почати користуватися

Правильна послідовність роботи:

1. Відкрийте сайт покупки BizGuard.
2. Увійдіть через Google.
3. Виберіть тариф і потрібну кількість активацій.
4. Завершіть оплату.
5. Скопіюйте повний ключ активації.
6. Перейдіть у застосунок BizGuard.
7. Увійдіть у Google-акаунт, Gmail якого потрібно захищати.
8. Вставте ключ активації.
9. Після підтвердження ключа відкриється панель аналізу листів.

Без Google-входу та активованого ключа перейти до аналізу Gmail неможливо.

## Де знайти придбаний ключ

Повний ключ доступний:

- одразу після успішної оплати;
- у профілі покупця біля відповідного замовлення.

Для копіювання натисніть `Копіювати ключ`. Ключ копіюється повністю, без скорочення.

Якщо старе замовлення було створене до підтримки повного відображення ключів, біля невикористаного ключа з’явиться кнопка `Показати повний ключ`. BizGuard безпечно перевидасть ключ і вимкне старий.

Якщо старий ключ уже активували, автоматичне перевидання недоступне. Це захищає чинні активації від випадкової втрати доступу.

## Активації

Одна активація відповідає одному Google-акаунту.

- повторний вхід того самого акаунта не витрачає нову активацію;
- інший Google-акаунт використовує ще одну активацію;
- після вичерпання ліміту новий акаунт активувати неможливо;
- строк дії ліцензії починається після першої успішної активації.

## Як перевірити листи

1. Відкрийте панель BizGuard.
2. Натисніть кнопку перевірки листів.
3. Дочекайтеся синхронізації Gmail.
4. Листи можуть деякий час мати статус очікування AI.
5. Після завершення аналізу відкрийте потрібний лист для перегляду деталей.

У детальному перегляді доступні:

- загальний бал загрози;
- AI-вердикт;
- оцінка домену;
- результати перевірки посилань;
- результати перевірки вкладень;
- технічні сигнали безпеки;
- коротке пояснення;
- рекомендовані дії.

## Рівні ризику

### Safe

Сильних ознак фішингу не знайдено. Все одно перевіряйте незвичні прохання про гроші, паролі або конфіденційні дані.

### Medium

Є підозрілі ознаки. Уважно перевірте адресу відправника, домен і посилання. Не вводьте пароль після переходу з листа.

### High

Виявлено серйозні сигнали небезпеки. Не відкривайте вкладення, не переходьте за посиланнями й не відповідайте на лист без додаткової перевірки.

### Critical

Лист має сильні ознаки фішингу або шкідливої активності. Не взаємодійте з ним. За можливості повідомте адміністратора або службу безпеки.

## Як працює AI

AI-аналіз виконується у фоновій черзі. `celery_ai_worker` бере лист на обробку, а локальний сервіс Ollama запускає мовну модель.

Окремого контейнера `llama_worker` немає і він не потрібен:

- `celery_ai_worker` керує задачами аналізу;
- `ollama` обслуговує AI-модель.

Якщо Ollama тимчасово недоступна, BizGuard не залишає лист назавжди без результату. Система формує резервну оцінку на основі домену, URL, вкладень і технічних ознак листа.

AI може помилятися. Результат BizGuard потрібно використовувати як рекомендацію з безпеки, а не як абсолютну гарантію.

## VirusTotal

VirusTotal використовується для перевірки репутації доменів, URL і підтримуваних вкладень.

Якщо ліміт VirusTotal тимчасово вичерпано, BizGuard продовжує аналіз за іншими сигналами. Після відновлення доступу зовнішні перевірки продовжаться автоматично.

## Довірені відправники

На річному тарифі можна додати довірений email або домен.

Додавайте лише адреси, якими ви впевнено керуєте або яким повністю довіряєте. Зловмисники можуть підробляти видиме ім’я відправника, тому не додавайте домен лише через знайомий логотип чи назву в листі.

## Конфіденційність і безпека

- Google-вхід відбувається через офіційний OAuth;
- пароль Google не передається BizGuard;
- доступ до Gmail використовується для синхронізації та дозволених дій із листами;
- ліцензійний ключ показується тільки власнику профілю покупки;
- ключі зберігаються у захищеному вигляді;
- не передавайте ключ, Google-токени або дані оплати стороннім особам.

Ви можете відключити Gmail-акаунт у BizGuard. Після відключення нові листи не синхронізуватимуться, доки ви не ввійдете через Google повторно.

## Локальний запуск

Для запуску власної копії потрібні Docker Desktop, Google OAuth credentials і PostgreSQL/Redis із Docker Compose.

1. Створіть локальний файл налаштувань:

```powershell
Copy-Item backend/.env.example backend/.env
```

2. Заповніть у `backend/.env`:

```env
GOOGLE_OAUTH_CLIENT_ID=...
GOOGLE_OAUTH_CLIENT_SECRET=...
LICENSE_KEY_HASH_SECRET=...
BILLING_LICENSE_ENCRYPTION_SECRET=...
VIRUSTOTAL_API_KEY=...
```

3. Запустіть BizGuard:

```powershell
docker compose up -d --build
docker compose exec backend python manage.py migrate
```

4. Відкрийте:

- BizGuard: `http://localhost:5173`
- сайт покупки: `http://localhost:5174`

## Запуск локальної AI-моделі

```powershell
docker compose --profile local-ai up -d ollama
docker compose --profile local-ai run --rm ollama_pull
docker compose up -d celery_ai_worker
```

Перевірити наявність моделі:

```powershell
docker compose --profile local-ai exec ollama ollama list
```

## Якщо щось не працює

### Google повідомляє `redirect_uri_mismatch`

Адреса callback у Google Cloud Console має повністю збігатися з адресою BizGuard, включно з протоколом, доменом, портом і шляхом.

### Після входу знову показується форма ключа

Це означає, що для цього Google-акаунта немає активної ліцензії. Вставте придбаний ключ або перевірте строк його дії.

### Листи довго мають статус очікування AI

Перевірте, що запущені Redis, `celery_ai_worker` та Ollama з потрібною моделлю.

```powershell
docker compose ps
docker compose logs -f celery_ai_worker
```

### Ключ не копіюється кнопкою

Дозвольте браузеру доступ до clipboard або виділіть ключ вручну та скористайтеся `Ctrl+C`.

### Аналіз не знаходить нові листи

Перевірте активність Gmail-акаунта, строк ліцензії та повторіть сканування. Якщо Google-доступ було відкликано, вийдіть із BizGuard і ввійдіть через Google ще раз.
